업무 추가

기능 사용법 보기
메모 · 업무에 참고할 내용을 적으면 업무 배너와 상세 화면에서 바로 확인할 수 있습니다.
체크리스트 · 한 업무를 작은 단계로 나눕니다. 저장 후 업무 배너에 항목이 한 줄씩 표시되고 바로 체크할 수 있습니다.
회신/대기 + 후속 확인일 · 상대방 답변을 기다리는 업무를 언제 다시 확인할지 기록합니다.
템플릿 · 자주 만드는 업무 내용을 저장해 다음 업무 등록 때 다시 불러옵니다.
알림 · 마감 기준 푸시 알림이며, 업무 메뉴의 “30분 뒤 알림”은 현재 업무를 다시 알리도록 예약합니다.
시간 선택 대신 직접 입력해도 됩니다. (24시간 기준)
회신/대기를 선택하면 상대방 답변을 다시 확인할 날짜를 지정할 수 있습니다.
회신/대기 업무를 다시 확인할 날짜입니다.
설정한 시간에 등록된 PC·휴대폰으로 푸시 알림을 보냅니다.
저장하면 업무 배너에 메모 제목과 함께 내용이 표시됩니다. 긴 메모는 배너에서 일부만 보이고 상세 화면에서 전체 내용을 볼 수 있습니다.
업무의 세부 단계입니다. 예: PO 확인 / 단가 확인 / 선적일 확인 / 회신. 저장하면 각 항목 이름이 업무 배너에 한 줄씩 표시되며 배너에서도 바로 체크할 수 있습니다.

비밀번호 재설정 요청

본인 이메일을 입력해 주세요.
요청이 관리자에게 전달됩니다. 관리자가 재설정 메일을 보내면 아래에 입력한 이메일의 받은편지함에서 WORK FLOW 재설정 링크를 확인할 수 있습니다.
WORK FLOW 계정으로 등록된 이메일을 입력해 주세요.

비밀번호 변경

첫 로그인 보안 설정
관리자가 발급한 임시 비밀번호는 한 번만 사용합니다. 새 비밀번호로 변경해야 업무 화면을 사용할 수 있습니다.
보안을 위해 새 비밀번호는 8자 이상 입력해 주세요. 현재 비밀번호와는 달라야 합니다.
